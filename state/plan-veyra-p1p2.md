### Approach decisions (documented, with the rejected alternatives)
1. Scaffold — **A: electron-vite + electron-builder (CHOSEN)** vs B: electron-react-boilerplate. A: researched 2026 default, react-ts template, electron-builder config built in, smaller opinionated surface to strip. B: batteries-included (menubar/i18n/CI) but heavy and harder to keep VEYRA-branded. Rejected B.
2. Local storage — **A: encrypted JSON store (CHOSEN for P1-2)** vs B: better-sqlite3. A: zero native deps, no rebuild/asarUnpack risk, settings are small; API key encrypted via Electron safeStorage (Windows DPAPI), everything else plaintext JSON under userData. B: real queryable DB but needs native rebuild + asarUnpack per dispatch, an ABI risk we do not take this pass. Revisit B in Phase 3 when transcript history needs querying. Rejected B now.
3. STT engine — **A: WhisperLiveKit v0.2.23 (CHOSEN)** vs B: whisper.cpp v1.9.0 prebuilt binaries. A: active (merged through 2026-08-01), Apache-2.0, native WebSocket streaming at ws://host:port/asr (PCM in, JSON partial/final out), `--model tiny|base|small`, runs on Windows (GPU auto-detect flaky — CPU mode fine for v1). B: single static binary, but whisper-stream needs SDL2 and whisper-server is HTTP request/response with token-streaming WS UNCONFIRMED (UNKNOWN) — that breaks the live-partial requirement. Rejected B. Both would sit behind the step-9 adapter, so a swap later is a seam change, not a rewrite.
4. Loopback capture — **A: electron-audio-loopback (CHOSEN)** vs B: native-audio-node. A: Electron >=31 patch over getDisplayMedia, no native rebuild. B: N-API module whose prebuilt ABI match for the target Electron is UNKNOWN (rebuild risk). Rejected B.
5. Mic capture — **A: renderer getUserMedia + AudioWorklet + IPC (CHOSEN)** vs B: main-process native N-API capture. A: zero native modules, standard Electron, works with the overlay. B: fewer IPC hops, native ABI risk. Rejected B.
6. Mic+loopback topology — **A: dual-track (CHOSEN)**: two streams, separate wlk sessions, source-labeled 'mic'/'loopback' so the me/other heuristic works. B: merged single stream: simpler, but speaker labeling becomes impossible. Rejected B.
